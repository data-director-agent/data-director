# Licence for the journal registry

`journals.jsonl`, built by `dd-journals fetch` from the snapshot that `manifest.json` pins, is
derived from the [OpenAlex snapshot](https://help.openalex.org/access/snapshot/), which OurResearch
releases under the [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) public
domain dedication. The registry is therefore available under CC0 1.0 too, separately from the MIT
licence that covers the code of this package. Source: OpenAlex (see `SOURCE.md` for the citation).
