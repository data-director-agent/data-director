# Project Charter

## Mission

`data-director` builds and maintains a reference implementation of the Research Data Alliance
(RDA) Data Director Agentic AI Blueprint, so that researchers and institutions have a working,
open example to adopt, adapt, and learn from.

## Scope

**In scope:**
- Implementing the components and behaviours described by the Blueprint.
- Maintaining conformance with the Blueprint as it evolves.
- Documentation, examples, and tooling that help others adopt the reference implementation.

**Out of scope:**
- Defining or amending the Blueprint specification itself — that is stewarded by its own RDA
  working group. This project consumes and implements the spec; it does not govern it.

## Roles

- **Maintainers** hold merge rights and are responsible for the project's technical direction and
  day-to-day decisions.
- **Contributors** are anyone who submits issues, pull requests, or documentation.

Full detail on how maintainers are added and how decisions are made lives in
[GOVERNANCE.md](../GOVERNANCE.md) — this charter describes why the project exists and what it is
for; GOVERNANCE.md describes how it runs.

## Values

- **Openness**: development happens in the open, in public issues and pull requests.
- **Community-driven decision-making**: lazy consensus and a lightweight RFC process (see
  GOVERNANCE.md) keep the bar for participation low while protecting spec conformance.
- **Alignment with RDA outputs**: the project tracks the Blueprint and credits the RDA working
  group that defines it.

## Amendments

Changes to this charter follow the same lazy consensus process used for code changes (see
[GOVERNANCE.md](../GOVERNANCE.md#decision-making-lazy-consensus)).
