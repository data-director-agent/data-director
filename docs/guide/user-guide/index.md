# User guide

The Data Director app lets you run agents that help with research data tasks. Every run is
governed by the harness and recorded, so you can see what an agent did and why.

1. [Getting started](getting-started.md): install and open the app.
2. [The workflow](workflow.md): the Blueprint's three entry points and six phases, a map of where
   you are and what the Data Director can help with.
3. [Running an agent](running-an-agent.md): choose an agent, give it input and read the result.
4. [Making an inventory](making-an-inventory.md): describe your dataset's files without sharing
   them, and attach the description to a conversation.
5. [Understanding outcomes](outcomes.md): what succeeded, abstained, referred and failed mean.
6. [What the Data Director records](records.md): what is kept about each run and conversation,
   where you can see it, and who else can.
7. [Giving feedback](feedback.md): tell the project where its advice, its specifications or its
   reading of the Blueprint fall short, without writing code.
