# User guide

The Data Director app lets you run agents that help with research data tasks. Every run is
governed by the harness and recorded, so you can see what an agent did and why.

1. [Getting started](getting-started.md): install and open the app.
2. [Running an agent](running-an-agent.md): choose an agent, give it input and read the result.
3. [Understanding outcomes](outcomes.md): what succeeded, abstained, referred and failed mean.
