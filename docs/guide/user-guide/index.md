# User guide

The Data Director app lets you run agents that help with research data tasks. Every run is
governed by the harness and recorded, so you can see what an agent did and why.

1. [Getting started](getting-started.md): install and open the app.
2. [The workflow](workflow.md): the Blueprint's three entry points and six phases, a map of where
   you are and what the Data Director can help with.
3. [The agents](agents.md): who the Data Director's agents are, what each helps with, what it
   sends to an AI model and what it will not decide for you.
4. [Using the conversation](conversation.md): the home page, writing and attaching, and the five
   stages shown while a message is answered.
5. [Running an agent](running-an-agent.md): choose an agent, give it input and read the result.
6. [Making an inventory](making-an-inventory.md): describe your dataset's files without sharing
   them, and attach the description to a conversation.
7. [Understanding outcomes](outcomes.md): what succeeded, abstained, referred and failed mean.
8. [Working on a project with others](members.md): add colleagues by ORCID iD, their roles,
   and what members see of one another's work.
9. [What the Data Director records](records.md): what is kept about each run and conversation,
   where you can see it, and who else can.
10. [Giving feedback](feedback.md): tell the project where its advice, its specifications or its
    reading of the Blueprint fall short, without writing code.
