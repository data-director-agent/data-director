# Alpha usage agreement

This is a short agreement for anyone using the Data Director **alpha prototype**. By using the
app you agree to it. If you do not agree, please do not use it.

!!! warning "No real data"
    Use **test or made-up data only**. Do not enter, upload or attach anything real: no personal
    data, no unpublished research, no confidential, commercially sensitive or licensed material,
    and nothing you would not be happy to see made public.

## What this is

Data Director is an early prototype, not a finished service. It is provided for trying out and
giving feedback. It may change, break, lose what you entered or be switched off without notice.

## What you agree to

1. **Use sample data only.** Everything you enter, including project descriptions, file names,
   ORCID iDs and documents, must be fictional or already public.
2. **Treat the advice as a draft.** Agents are AI and can be wrong. Check anything they suggest,
   such as repository choices, metadata and licences, before you rely on it.
3. **Expect no guarantees.** There is no promise of availability, security, accuracy or support,
   and no warranty of any kind. Do not rely on the app for any real deposit or deadline.
4. **Keep it fair.** Do not try to break, overload or get around the app, and do not use it for
   anything unlawful or harmful.
5. **Share feedback if you can.** Feedback is welcome, but it is public on GitHub, so keep it
   free of personal or confidential data. See [Giving feedback](feedback.md).

## What the people running it may do

Whoever runs the instance may log activity to keep it working and to improve it. Because only
test data should be present, they may delete everything in it at any time. Which AI models an
instance calls, and where, is set by its operators; see the [operations guide](../operations/index.md).

If you think real data has been entered by mistake, tell the instance's operators straight away so
that it can be removed. How the project handles personal data is in the [privacy notice](../privacy.md).

## Changes

This agreement may be updated as the project matures, and it will be replaced before any release
that handles real data.
