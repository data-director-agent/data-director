# Data Director

Data Director is a reference implementation of the RDA
[Data Director Agentic AI Blueprint](https://www.rd-alliance.org/groups/data-director-agentic-ai-blueprint/outputs/data-director-agentic-ai-tool-blueprint/),
published at <https://doi.org/10.15497/RDA00157>.

!!! note "Alpha"
    The app and several agents are alpha software. Their shape will change.

## Where to start

- **[User guide](user-guide/index.md)**: run the app, run an agent and read what comes back.
- **[Developer guide](developer-guide/index.md)**: set up the repository, write an agent and
  work on these pages.
- **[Reference](reference/index.md)**: the contract, decisions, glossary and conformance report.
