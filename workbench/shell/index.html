    Getting started

    1. Choose an agent. The card beneath it says what the agent does and which inputs it accepts.
    2. Choose a sample input. Only samples the agent accepts are listed.
    3. Press Run, or Ctrl+Enter.

    Or open an earlier run from Stored runs. Each run returns one envelope: an outcome, the agent's payload if it succeeded, the evidence the payload rests on, and telemetry. Press ? beside a term for an explanation, or open the Glossary.
