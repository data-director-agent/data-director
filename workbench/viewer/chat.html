    Chatting with an agent

    1. The picker starts on the orchestrator, if one is registered. Any other agent can be chosen instead.
    2. An agent that accepts a Message gets a text box. Any other agent gets its input as JSON, started from a sample.
    3. Every reply names the agent and version that produced it. An orchestrator's reply lists the invocations it delegated, each with its own agent and version.

    Each turn is one invocation with its own envelope; Inspect on a reply opens it. Changing agent starts a new conversation.
