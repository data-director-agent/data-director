# Data Management Plan: Peatland Carbon Flux at Ringinglow Bog

Synthetic plan written for the advisor.dmp evaluation. The project, people and data are invented.

## 1. Data collection

The project will run an eddy covariance tower on Ringinglow Bog for three years, logging carbon
dioxide and methane fluxes every 30 minutes. Twice a year we will take soil cores at twelve plots
and analyse them for carbon, nitrogen and pH. Fieldwork notes will be kept in paper notebooks.

## 2. Documentation and metadata

Each dataset will be described with a README and a data dictionary, and catalogued with
discovery metadata following the UK GEMINI standard.

## 3. Storage and backup

During the project, data will be held on the university's research storage, which is backed up
nightly to a second site.

## 4. Data sharing

The quality-controlled eddy covariance flux data will be deposited in the NERC Environmental
Information Data Centre (EIDC) and made openly available under the Open Government Licence after
a 12-month embargo from the end of the final field season.

The soil core chemistry dataset will also be deposited in the EIDC, openly available under the
Open Government Licence, within three months of the final laboratory analysis.

All processing code will be released on GitHub and archived in Zenodo with a DOI, openly available
under the MIT licence, when the first paper is submitted.

## 5. Responsibilities

The principal investigator is responsible for the plan; the project's research data manager will
review it every six months.
