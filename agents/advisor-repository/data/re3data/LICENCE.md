# Licence for `snapshot.jsonl`

The records in `snapshot.jsonl` are taken from the metadata records of
[re3data.org](https://www.re3data.org), fetched through the API route named in `manifest.json`
on the date it records. re3data publishes its metadata under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), so this file and `manifest.json`
carry no conditions. They are attributed to re3data.org nonetheless.

Only the fields read in `src/dd_agent_advisor_repository/records.py` are kept. Repository contact
details are not copied.
