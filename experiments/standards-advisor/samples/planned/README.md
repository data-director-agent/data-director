# Upland grassland restoration monitoring, Peak District, 2027–2029

This project will monitor soil and vegetation recovery across upland grassland plots undergoing
restoration in the Peak District National Park. Forty permanent plots will be established across
three restoration treatments and one untreated control, and each plot will be revisited annually
for three years.

Each visit will record soil chemistry from topsoil and subsoil cores, vegetation composition by
quadrat, and the time and duration of the survey. Sampling will follow a stratified design with
plots allocated by land-use history. No data has been collected yet: this documentation is being
drafted before the first field season so that recording conventions can be agreed in advance.

Keywords: upland grassland, restoration ecology, soil chemistry, vegetation survey, Peak District

## Data collection

Soil cores will be taken with a soil auger and analysed in the laboratory for pH, organic carbon
and total nitrogen. Vegetation will be recorded by percentage cover in fixed quadrats.
